Changelog

All notable changes to this project will be documented in this file.

[2.0.0] — 2026-08-11

🚀 Major Update

- Added a new and improved autocomplete database.
- Added "autocomplete.json" with 1,953+ Lua/SA-MP entries.
- Improved autocomplete accuracy and suggestions.
- Improved plugin performance and responsiveness.
- Updated autocomplete support for MoonLoader / MonetLoader.
- Improved project structure and plugin configuration.
- Updated plugin metadata and documentation.
- Improved overall compatibility with Acode.

✨ Improvements

- Cleaner autocomplete results.
- More complete SA-MP Lua function coverage.
- Improved organization of autocomplete entries.
- Reduced unnecessary processing when searching suggestions.
- Improved maintainability of the autocomplete database.

🐛 Fixes

- Fixed several incorrect or missing autocomplete entries.
- Fixed issues with autocomplete suggestions not appearing correctly.
- Fixed minor plugin initialization issues.
- Fixed various compatibility issues.

📦 Files

- "main.js" — Plugin logic.
- "autocomplete.json" — Autocomplete database.
- "plugin.json" — Acode plugin metadata.
- "icon.png" — Plugin icon.
- "banner.png" — Project banner.

[1.0.0]

Initial Release

- Initial release of Lua SA-MP Autocomplete for Acode.
- Added basic Lua/SA-MP autocomplete functionality.
- Added Acode plugin configuration.
- Added initial autocomplete database.
